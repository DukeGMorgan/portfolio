Clinical informatics / AI-assisted schema intelligence

Make a 600+ table clinical database easier to understand.

A schema assistant turns an unfamiliar 600+ table data model into an immediate, governed starting point for investigation and analyst enablement.

The problem

Troubleshooting an enterprise EMR across a multi-clinic network requires knowing how its data fits together. With more than 600 tables, learning the schema becomes part of every investigation and a major bottleneck for analysts.

What I built & enabled

I built an AI-assisted query and schema intelligence tool grounded in the clinical SQL Server data dictionary. Its scope is strictly metadata and schema: it guides investigation structure while enforcing air-tight data boundaries that keep patient records outside the assistant.

What changed

Analysts navigate complex relational schemas in minutes rather than hours, dramatically shortening root-cause investigation cycle times and accelerating onboarding across the clinical systems team.

Clinical AI / Enterprise governance & routing architecture

Give clinical AI a controlled place to run.

The data boundary is an architectural mandate that every model, agent, and workflow must respect.

The problem

What changed

Clinical and operational teams adopt AI with defined execution paths, auditable access boundaries, and zero risk of unauthorized PHI egress.

Clinical Data Migration

9 hrs → <6 min

Onboard an active primary EMR into a unified multi-clinic viewer.

Problem: Our multi-clinic viewer (3M+ records across 4 legacy EMRs) had never ingested data directly from our active primary EMR—over 1M rows with undocumented schemas and mis-encoded binary documents.

Solution: Built a batched bulk-loader pipeline, a standalone binary document encoding repair utility, and a reusable vendor migration profile.

Impact: Migrated 11,600+ patients and 1.3M+ records in under 6 minutes (down from ~9 hours), creating a repeatable onboarding blueprint for future clinics.

  • Bulk ETL
  • SQL Server
  • Binary Repair
  • 1.3M+ Records

Permission Governance

14 Sites · 177 Changes

Revoke sensitive clinical access safely across a multi-clinic network.

Problem: The EMR’s additive security model lacked "deny" semantics. Manually revoking Billing Write access across 14+ clinics risked raw SQL errors and silent vendor audit-trail gaps.

Solution: Built a dry-run-first CLI wrapping vendor stored procedures to preview full before/after states, verify audit logging, and capture row-level rollback snapshots.

Impact: Completed 177 verified revocations across 14 production centers with zero data loss, exposed a vendor audit-logging defect, and caught live unauthorized re-grants within minutes.

  • Access Governance
  • Dry-Run CLI
  • Audit Forensics
  • Rollback Safety

Core Clinical Engineering

196 Tests · 0 Regressions

Modernize a 39-category legacy chart-merge engine in native TypeScript.

Problem: Complex patient chart merges—covering 39 data categories, gap repairs, and cascade reversions—lived in a brittle legacy service outside our modern enterprise operations stack.

Solution: Executed a 10-phase port into TypeScript, engineering every merge category as a builder/reverser pair with pre-mutation backups and compile-time clinic registries.

Impact: Deployed with 196 passing automated tests and zero regressions, enabling safe, instantaneous chart merges across any configured clinic from one unified interface.

  • TypeScript
  • Builder/Reverser
  • 196 Unit Tests
  • Zero Regressions

HIPAA / BAA AI Architecture

Zero PHI Egress

Enable AI-assisted clinical database forensics without exposing PHI.

Problem: Repetitive clinical data investigations (duplicate charts, ID collisions, population anomalies) were ideal for AI, but HIPAA rules bar raw patient data from commercial AI stacks.

Solution: Built a guarded local query proxy and BAA-governed read-only investigator that validates schema paths against injection, routes raw results to an isolated HIPAA de-identification layer, and returns only scrubbed summaries.

Impact: Shifted effort from manual SQL querying to strategic investigation briefs—accelerating root-cause analysis inside an auditable, zero-leak boundary.

  • HIPAA / BAA

Clinical Workflow Automation

Hand-Typed → Auto-Filled

Automate clinic requisitions with an EMR Bookmark Mapping engine.

Impact: Eliminated repetitive manual typing on high-volume clinical forms while preventing teams from over-promising unsupported vendor fields to clinics.
